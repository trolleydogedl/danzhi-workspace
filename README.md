# 旦知（Danzhi）workspace

复旦校园小助手：信匣、课表、生活码、空教室。给下一轮对话用的完整工程快照。

## 下一对话请发这些链接

- 仓库：https://github.com/trolleydogedl/danzhi-workspace
- GitHub zip：https://github.com/trolleydogedl/danzhi-workspace/archive/refs/heads/main.zip
- Litterbox 直链 zip（72 小时）：见本轮聊天最后一条

把 zip 解到 `/workspace` 后即可继续改代码、打安装包。**不要把 UIS 密码提交进仓库。**

## 当前版本

Android 安装包 **1.25.0**（`public/danzhi-1.25.0.apk` / `artifacts/danzhi-1.25.0.apk`）。

本轮相对 1.24 的修复：

- 图标改成真正能看清的「旦」：日是上下两格窗口，下面一横更长更粗
- 点「刷新生活码」不再被登录锁挡住；码面未轮换也会更新时间戳
- 设置主题增加到 30 种
- 源码与安装包版本对齐，避免再下到旧的 1.19

网页预览只是看板。登录、巡检、闸机请用安装包。
